The fixture used one local bare remote and three independent clones, with 32 feature branches per clone, two linked worktrees per clone, staged and unstaged versions of one file plus a tracked edit in `base.txt` per checkout, two untracked files per checkout, and 1,000 non-repository directory groups. Total: 105 local heads, six linked worktrees, 18 untracked files, and 33 target remote branches. Fixture setup took 5 seconds.

Preservation completed for all three clones and recorded 123 recovery refs. Independent verification passed for all three. Preview reported all three blocked at the deletion boundary, as configured; no cleanup command ran. No network remote or LFS payloads were used. Stage wall time totals 137.82 seconds, excluding fixture setup.

This is one sample, not a cold/warm comparison: filesystem and OS cache state was not controlled. Git child counts are Trace2 `child_start` events and may omit subprocesses that do not inherit Trace2 settings. Max RSS is the value reported by `/usr/bin/time -l`; it is not a separately measured aggregate of all child processes. Stdout/stderr sizes do not measure pack or network transfer bytes; transfer bytes were not instrumented. The fixture had no large blobs, long or divergent histories, or historical LFS pointers. It does not establish whole-machine discovery coverage or GitHub network/LFS performance.
